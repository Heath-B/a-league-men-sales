# A-League Men Player Sales

A dataset of departures from A-League Men clubs that returned money to the selling club, covering the 2019/20 season to the 2026/27 mid-year window.

No public register of A-League transfer income exists. Clubs are under no obligation to disclose fees and most do not. This dataset records the departures where the available evidence supports reasonable confidence that a club recouped money, and documents the reasoning behind every entry.

## What is here

`A-League-Men-Player-Sales-Dataset-and-Method.pdf` is the method document. It sets out what counted as money returned to a club, how competing sources were ranked where they disagreed, and how each entry was graded for evidence. It then works through each transfer cycle in turn, covering both the departures that qualified and the near misses that did not.

Citations are hyperlinked throughout, so each entry leads straight to the club statement or report it rests on.

## Scope

128 departures were included, drawn from 1,264 in the competition-level record. That figure is not a count of how many sales occurred. It is the number the available evidence supports, and it almost certainly understates the true total.

22 entries are flagged, each against a stated rule, so a reader can see where the evidence is thinnest.

## Status

The dataset is complete for the period above. The analysis is in progress and findings will be published separately.
